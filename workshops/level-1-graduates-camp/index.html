🚀 مخيم تجهيز الخريجين: من مشروع التخرج لأول وظيفة

إذا انت خريج أو على أبواب التخرج، وبدك تبني مشروع تخرج قوي، أو مشروع حقيقي تحطّه بالـ CV وتقدّم فيه على الشغل وانت واثق من حالك، هاد المخيم إلك 👌

👨‍💻 المحاضر: م. مصعب عطية، Full Stack Developer شغّال بمجال تطوير البرمجيات

🎯 شو الفكرة؟

مخيم عملي بعيد عن جو المحاضرات الجامعية. التركيز على التطبيق وفهم الأمور بشكل عميق ومن الأساس، مش حفظ وتلقين.

بتطلع آخر المخيم بـ مشروع Full Stack متكامل مبني من الصفر، مرفوع على GitHub وشغّال على سيرفر.

استثمر بحالك: ابنِ المشروع بإيدك بدل ما تشتري مشروع جاهز. بتطلع بمهارة، مش بس معلومة.

🧱 ليش مش تشتري مشروع جاهز؟

المشروع الجاهز بيبيّن أسهل، بس بيوقف عند أول سؤال باللجنة: "ليش عملتها هيك؟" ونفس السؤال رح يجيك بالإنترفيو.

هون بتبني مشروعك بإيدك، خطوة خطوة. لما تكون انت كاتب كل سطر، بتعرف تشرحه وتدافع عنه وتعدّل عليه.

والمستوى 1 كله عن الأساس: مش بس "كيف" نكتب الكود، كمان "ليش" بيشتغل وشو بيصير ورا الكواليس. الحفظ بيروح، والفهم بيضل معك.

🤝 معك لآخر الفصل

اللقاءات بتخلص بعد 6 أسابيع، بس المتابعة ما بتخلص معها. بنضل معك لآخر الفصل:

  • بتضل بجروب التلغرام الخاص بالدفعة، وبتسأل إذا وقفت عند شي
  • مراجعة دورية لمشروعك: بنشوف وين وصلت، وبتاخد ملاحظات والخطوة الجاية

وخليني أكون واضح: المتابعة يعني توجيه ومراجعة. الكود انت بتكتبه، واحنا ما بنكتب المشروع عنك.

  • ℹ️ أيام اللقاءات ممكن تتغير حسب الجروب، وبنبلّغكم قبلها بوقت كافي.

📚 المحتوى

🔹 المرحلة 1: الأساسيات والأدوات (الأسبوع 1)

  • Git و GitHub: Commits, Branches, Pull Requests
  • هيكلة المشروع وتحليل المتطلبات قبل كتابة الكود

🔹 المرحلة 2: الـ Backend بـ C# (الأسابيع 2-3)

  • C# و OOP بشكل عملي
  • ASP.NET Core Web API
  • REST API: Routing, Controllers, HTTP Methods
  • التعامل مع قاعدة البيانات باستخدام ADO.NET (SQL Server): كتابة الـ Queries باليد وفهم شو بيصير فعلياً ورا الكواليس، بدون الاعتماد على أدوات بتخبّي التفاصيل
  • Validation و Error Handling
  • Authentication و Authorization

🔹 المرحلة 3: الـ Frontend (الأسابيع 4-5)

  • HTML و CSS: تصميم صفحات مرتبة و Responsive
  • JavaScript: DOM و Events
  • ربط الواجهة مع الـ API باستخدام Fetch

🔹 المرحلة 4: النشر والجاهزية للشغل (الأسبوع 6)

  • نشر المشروع على IIS
  • ترتيب الـ GitHub والـ README بشكل احترافي
  • كيف تكتب المشروع بالـ CV وتحكي عنه بالإنترفيو

💼 وطول المخيم: نصائح وخبرات عملية من الشغل الحقيقي بالشركات: كيف بيشتغلوا، شو بيدوّروا عليه، وشو الأخطاء اللي لازم تتجنبها.

🛠️ شو رح تبني؟ (أمثلة مقترحة)

كل طالب بيختار فكرة وبيبنيها بإيده. أمثلة مناسبة لمشروع تخرج، أو مشروع للـ CV، أو كبداية لشغل فريلانس:

  1. نظام حجز مواعيد لعيادة: مرضى، أطباء، مواعيد، صلاحيات (Admin / Doctor / Receptionist)، منع تعارض المواعيد.
  2. نظام إدارة مخزون لمحل أو مستودع: أصناف، موردين، حركات إدخال/إخراج، تنبيه نقص الكمية، تقارير بسيطة.
  3. نظام إدارة دورات/مركز تدريب: دورات، مدربين، طلاب، تسجيل، حضور وغياب، علامات.

بتقدر تقترح فكرتك الخاصة، بشرط تكون بحجم مناسب لـ 6 أسابيع (بنتفق عليها بأول أسبوع).

🎓 ما في شهادة — شهادتك هي مشروعك: على GitHub، شغّال على سيرفر، وانت بتقدر تشرحه سطر سطر.

👥 لمين هاد المخيم؟

  • طلاب السنة الأخيرة اللي بدهم مشروع تخرج يفهموه ويقدروا يدافعوا عنه
  • الخريجين اللي بدهم مشروع حقيقي بالـ CV وبالإنترفيو
  • اللي بدهم يتحولوا لمجال البرمجة وعندهم أساسيات وجاهزين يتعبوا

🚫 مش إلك إذا...

  • بدك مشروع جاهز تسلّمه بدون ما تكتبه
  • بدك تحضر وتسمع بس بدون ما تطبّق وتحل واجبات
  • ما عندك وقت أسبوعي للتطبيق خارج اللقاءات
  • بتدوّر على ضمان وظيفة: المخيم بيعطيك مهارة ومشروع وطريقة تحكي عنه، بس الوظيفة بتعتمد على شغلك وعلى السوق
  • بدك شهادة ورقية: ما في شهادة بهاد المخيم

📝 طريقة الشغل وشو المطلوب منك

  • المحاضر بيشرح وبيطبّق قدامك خطوة بخطوة
  • انت مطلوب منك تطبّق بنفسك وتحل الواجبات بعد كل لقاء
  • تسليم الواجب بيكون بداية كل لقاء جديد (كـ commit أو Pull Request على GitHub)
  • الطالب عليه جزء أساسي: اللي بيشتغل بيطلع بنتيجة حقيقية 💪

⚠️ المخيم مش للي بده يسمع ويروّح، هو للي جاهز يشتغل ويتعب على حاله.

🔍 كيف بنتابع معك؟

  • كل لقاء: أول 10-15 دقيقة مراجعة الواجب: ✅ مكتمل · ◐ جزئي · ❌ ما انسلّم
  • محطات المشروع:
    • الأسبوع 1-2: تحليل المتطلبات وتصميم قاعدة البيانات
    • الأسبوع 3: الـ API شغّال
    • الأسبوع 5: الواجهة مربوطة مع الـ API
    • الأسبوع 6: المشروع منشور + README مرتب
  • المراجعة النهائية: عرض قصير للمشروع + تقييم حسب معايير واضحة + 3 ملاحظات مكتوبة (نقطة قوة، شي لازم يتصلّح، الخطوة الجاية)
  • بعد آخر لقاء ولآخر الفصل: أسئلة على جروب التلغرام الخاص بالدفعة + مراجعة دورية لمشروعك. انت بتكتب الكود، واحنا بنوجّه وبنراجع.

معايير التقييم (كل معيار من 1 لـ 4): تحليل المتطلبات وتصميم الـ DB · صحة الـ API · جودة الكود · الواجهة (شغّالة و Responsive) · استخدام Git · النشر والـ README · الالتزام بالواجبات.

✍️ كيف بسجّل؟

  1. عبّي نموذج التسجيل هون على الموقع (اسمك، إيميلك، عمرك، وضعك الحالي، اسم جامعتك إذا كنت طالب أو خريج، والهدف من المشروع). بياخد دقيقة.
  2. قبل بداية المخيم بنتواصل معك على الإيميل وبنبعتلك رابط Teams.
  3. بتحضر أول لقاءين تجربة بدون دفع.
  4. إذا قررت تكمّل: بتدفع 110 دنانير عن طريق CliQ بعد اللقاء الثاني، وبنضيفك لجروب التلغرام الخاص بالدفعة.

عندك سؤال قبل ما تسجّل؟ راسلنا على التلغرام.

❓ أسئلة شائعة

كيف بسجّل وشو بصير بعدها؟ بتعبّي نموذج التسجيل على الموقع، وبنرد عليك على الإيميل برابط Teams قبل البداية. بتحضر أول لقاءين تجربة بدون دفع، وإذا كمّلت بتدفع عن طريق CliQ وبنضيفك لجروب التلغرام الخاص بالدفعة.

إمتى بنضاف لجروب التلغرام؟ بعد اللقاء الثاني، لما تقرر تكمّل وتدفع. قبل هيك التواصل بيكون على الإيميل، والتلغرام للأسئلة بس.

لازم يكون عندي خبرة قبل؟ لازم تعرف أساسيات البرمجة بأي لغة. ما بنبدأ من "شو يعني متغير".

رح أطلع بمشروع جاهز؟ رح تطلع بمشروع انت كتبته. إذا ما طبّقت وحليت الواجبات، ما رح يكون عندك مشروع كامل.

شو يعني متابعة لآخر الفصل؟ بعد آخر لقاء ما بتنقطع عنّا: لآخر الفصل بتضل بجروب التلغرام الخاص بالدفعة وبتسأل لما توقف عند شي، وبنعمل مراجعة دورية لمشروعك (بنشوف وين وصلت وبنعطيك ملاحظات والخطوة الجاية). اللي مش داخل فيها: ما بنكتب الكود ولا المشروع عنك. المتابعة توجيه ومراجعة، والشغل عليك. وهي لآخر الفصل، مش لحد التخرج أو لحد ما تلاقي شغل.

بتضمنولي وظيفة؟ لا. ما في حدا بيقدر يضمن وظيفة بصدق. اللي بنقدمه: مهارة عملية، مشروع حقيقي على GitHub، ونصائح كيف تعرضه بالـ CV وبالإنترفيو.

في شهادة؟ لا، ما في شهادة. شهادتك هي مشروعك: مرفوع على GitHub، شغّال على سيرفر، وانت بتقدر تشرحه بالمناقشة وبالإنترفيو.

المشروع بنفع كمشروع تخرج؟ غالباً نعم، بس لازم تتأكد من متطلبات جامعتك ومشرفك. المشروع إلك وانت بتفهمه سطر سطر، وهاد أهم شي بالمناقشة.

ليش ADO.NET مش Entity Framework؟ عشان تفهم شو بيصير فعلياً مع قاعدة البيانات وتكتب الـ SQL بإيدك. الـ EF Core والـ Patterns الأكبر موجودين بالمستوى 2.

المخيم أونلاين ولا حضوري؟ أونلاين بالكامل على Microsoft Teams.

شو لغة الشرح؟ العربي، والمصطلحات التقنية بتضل بالإنجليزي (زي Git و REST API و ADO.NET) لأنه هيك بتلاقيها بالشغل.

إمتى بيبدأ وشو المواعيد؟ البداية الاثنين 21 كانون الأول 2026 (أول لقاء) والنهاية الأربعاء 27 كانون الثاني 2027، لقاءين بالأسبوع (الاثنين والأربعاء)، 3 ساعات كل لقاء، 7:00 – 10:00 مساءً بتوقيت الأردن. الأيام ممكن تتغير حسب الجروب، وبنبلّغكم قبلها بوقت كافي.

قديش السعر؟ 110 دنانير أردنية، بتدفعها عن طريق CliQ بعد اللقاء الثاني إذا قررت تكمّل. أول لقاءين تجربة بدون دفع.

إذا انسحبت؟ في استرجاع؟ إذا انسحبت خلال أول لقاءين ما بتدفع شي. بعد ما تدفع (بعد اللقاء الثاني) ما في استرجاع، فخذ قرارك بعد التجربة.

في عدد محدد للمقاعد؟ لا، ما في عدد ثابت لهاي الدفعة.

إذا غبت عن لقاء؟ اللقاءات مباشرة (Live) بس، وما في تسجيلات. إذا غبت، انت المسؤول تلحق: تحل واجب اللقاء، تتابع الـ repo وتحدّث مشروعك، وتسأل على التلغرام إذا وقفت عند شي. الغياب المتكرر بيأثر على مشروعك، فخطّط إنك تحضر كل اللقاءات.

شو بحتاج على اللابتوب؟ لابتوب Windows (عشان بنشتغل على SQL Server وبننشر على IIS)، وعليه هاي الأدوات، وكلها مجانية:

  • Visual Studio Community (بيجي معه .NET SDK)
  • SQL Server Express + SQL Server Management Studio (SSMS)
  • VS Code (للـ HTML/CSS/JS)
  • Git + حساب على GitHub

بنساعدك بالتنزيل بأول لقاء إذا احتجت.
